# План публикации в RuStore

## Требования RuStore

### 1. Аккаунт разработчика
- [ ] Зарегистрироваться на [console.rustore.ru](https://console.rustore.ru) как разработчик
- [ ] Верифицировать аккаунт (документы для юрлица или ИП/физлица)
- [ ] Заполнить информацию о разработчике

### 2. Технические требования к APK
- [ ] **Подпись APK** — релизный APK должен быть подписан ключом разработчика
- [ ] **Version Code/Name** — проставить корректные версии в `android/app/build.gradle` и `capacitor.config.ts`
- [ ] **Target SDK** — проверить соответствие требованиям RuStore (обычно targetSdkVersion >= 33)
- [ ] **Min SDK** — установить разумный минимум (рекомендуется 24+)
- [ ] **Test APK** — протестировать установку и работу на реальных устройствах Android

### 3. Материалы для карточки приложения

#### Обязательные
- [ ] **Иконка 512x512** — PNG, без альфа-канала, без скруглений (RuStore обрезает сам)
- [ ] **Скриншоты** — минимум 2, максимум 8 (разрешение 1080x1920 или 1080x2400, PNG/JPEG)
- [ ] **Краткое описание** — до 80 символов
- [ ] **Полное описание** — до 4000 символов
- [ ] **Категория** — «Здоровье» или «Продуктивность»
- [ ] **Возрастной рейтинг** — «Для всех возрастов» (3+)
- [ ] **Контактный email** — для обратной связи

#### Дополнительные
- [ ] **Видео-превью** — опционально, до 30 секунд
- [ ] **Ссылка на политику конфиденциальности** — есть в приложении (О приложении → Политика конфиденциальности)
- [ ] **Ссылка на пользовательское соглашение** — если требуется

## Тексты для RuStore

### Краткое описание (до 80 символов)

> AI-помощник по питанию. Анализ еды, чат, дневник, каталог продуктов.

### Полное описание

NutriAdvisor — AI-помощник для осознанного питания и здорового образа жизни. Приложение помогает анализировать рацион, отслеживать КБЖУ и получать персонализированные рекомендации от нейросети.

**Возможности:**

**Анализ питания**
- Анализ еды по фото или текстовому описанию — AI рассчитает калории, белки, жиры и углеводы
- Стриминг ответов в реальном времени — результат появляется по мере генерации
- Поддержка составных блюд из нескольких ингредиентов с точным расчётом КБЖУ по каждому

**Каталог продуктов и блюд**
- Создайте свой каталог продуктов с указанием калорийности и нутриентов
- Составляйте рецепты блюд из каталога — ингредиенты и граммовки
- Быстрое добавление в журнал питания из каталога в пару нажатий

**Журнал питания**
- Структурированные записи с перечнем продуктов и блюд
- Шаблоны приёмов пищи — копируйте ранее записанный приём как основу для нового
- Группировка по дням, просмотр истории

**AI-чат ассистент**
- Персонализированные рекомендации с учётом вашего профиля, целей и ограничений
- Подключите контекст: данные питания, активностей и дневника за выбранный период
- Множественные диалоговые сессии с навигацией

**Дневник самочувствия**
- Записи об активности, самочувствии и измерениях давления
- Интеграция с AI — нейросеть учитывает данные дневника при рекомендациях
- Сводка за день

**10 предустановленных целей питания**
- Здоровье, похудение, набор массы, набор мышц, сушка
- Улучшение сна, самочувствие, бодрость ума, энергия, поддержание веса
- Возможность создать свои пользовательские цели

**Конфиденциальность**
- Все данные хранятся локально на устройстве — приложение не создаёт серверных профилей
- Экспорт/импорт всех данных в JSON для переноса между устройствами
- Возможность подключить локальные модели (Ollama) для полной приватности

**Готово к работе сразу после установки**
- Предустановлен AI-провайдер — можно начинать пользоваться без настройки ключей
- Поддержка собственных провайдеров: OpenAI, Google AI Studio, OpenRouter, Ollama и других

### Ключевые слова (для поиска)

## Чек-лист перед публикацией

### Сборка
- [ ] `npm run build` — успешная сборка Next.js (static export)
- [ ] `npm run build:android` — синхронизация с Android-проектом
- [ ] Создать keystore: `keytool -genkey -v -keystore nutriadvisor.keystore -alias nutriadvisor -keyalg RSA -keysize 2048 -validity 10000`
- [ ] Собрать подписанный APK
- [ ] Установить на тестовое устройство, проверить работу

### Проверка приложения
- [ ] Первый запуск — провайдер по умолчанию подключен, чат работает
- [ ] Анализ еды по тексту — корректный расчёт КБЖУ
- [ ] Анализ еды по фото — камера работает, результат корректный
- [ ] Журнал — добавление, редактирование, удаление записей
- [ ] Каталог — CRUD продуктов и блюд
- [ ] Дневник — записи активностей, самочувствия, давления
- [ ] Профиль — заполнение, цели, экспорт/импорт данных
- [ ] Чат — стриминг, несколько сессий, контекст
- [ ] Кнопка «О приложении» — Hilfe отображается корректно
- [ ] Политика конфиденциальности — отображается, дата актуальная

### RuStore
- [ ] Загрузить APK в консоль RuStore
- [ ] Заполнить карточку приложения (тексты выше)
- [ ] Загрузить иконку и скриншоты
- [ ] Указать категорию и возрастной рейтинг
- [ ] Отправить на модерацию
- [ ] После одобрения — опубликовать
