# NutriAdvisor

**AI-помощник по питанию** — мобильное приложение (PWA + Android APK) для персонализированного анализа и коррекции питания.

Приложение помогает скорректировать питание исходя из ваших целей (похудение, набор массы, улучшение сна и др.), анализирует съеденные продукты через текст или фото, даёт рекомендации через AI-ассистента и ведёт журнал питания.

> **Бессерверный режим** — все данные и история хранятся локально на устройстве. API ключи для LLM также хранятся только у вас. Никаких серверных компонентов.

---

## Возможности

### LLM и анализ
- **Конфигурируемые LLM-провайдеры** — OpenAI, OpenRouter, Alibaba DashScope, Ollama (локальный), llama.cpp, произвольные. Добавляйте, редактируйте, удаляйте провайдеров и переключайтесь между ними.
- **Анализ еды по фото** — снимок камеры или выбор из галереи. Vision-модель описывает блюдо, затем AI оценивает КБЖУ с учётом указанных описания и веса порции.
- **Анализ еды по тексту** — введите описание блюда и вес, AI оценит калорийность и макронутриенты.
- **Стриминг ответов LLM** — ответы чата появляются в реальном времени по мере генерации. Кнопка остановки для прерывания генерации.
- **10 целей питания** — здоровье, похудение, набор массы, набор мышц, сушка, улучшение сна, самочувствие, бодрость ума, энергия, поддержание веса.

### Чат и контекст
- **AI-чат ассистент** — диалоговый интерфейс с контекстными рекомендациями. Автоматически определяет тему сообщения и подбирает системный промпт.
- **Контекст питания в чате** — подключайте к диалогу данные за сегодня, неделю или месяц. AI видит что вы ели и даёт рекомендации с учётом реального рациона.
- **Множественные диалоги** — сессии чата с навигацией по датам в боковой панели.
- **Редактирование сообщений** — отредактируйте любое сообщение пользователя и переотправьте диалог с этой точки.
- **Переименование сессий** — двойной клик или кнопка для переименования разговора.

### Журнал питания
- **Журнал с группировкой по датам** — записи группируются по дням с пейджингом для навигации по истории.
- **Проверка КБЖУ** — после AI-анализа значения калорий, белков, жиров, углеводов можно скорректировать вручную перед сохранением.
- **Предупреждение о неполных данных** — если AI не определил какой-то макронутриент, система уведомит и предложит повторить анализ или заполнить вручную.

### Данные и экспорт
- **Экспорт/импорт данных** — полная резервная копия всех данных (провайдеры, профиль, журнал, чат) в JSON-файл для переноса между устройствами.
- **Профиль пользователя** — параметры тела, уровень активности, ограничения в питании, медицинские заметки.
- **Дашборд** — сводка КБЖУ за день, прогресс по целям, быстрые действия.

### Платформы
- **PWA** — устанавливается через браузер (Добавить на главный экран).
- **Android APK** — сборка нативного приложения через Capacitor (см. раздел «Сборка Android APK»).
- **Markdown-рендеринг** — ответы LLM отображаются с форматированием (заголовки, списки, таблицы, код, цитаты) без внешних зависимостей.

## Установка и запуск

### Требования

- **Node.js** 18+ или **Bun** 1.0+
- **npm**, **yarn** или **bun**

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/NikasAl/NutriAdvisor.git
cd NutriAdvisor
```

### 2. Установите зависимости

```bash
npm install
# или
bun install
```

### 3. Запустите в режиме разработки

```bash
npm run dev
# или
bun run dev
```

Приложение будет доступно по адресу **http://localhost:3000**.

### 4. Сборка для продакшена (PWA / веб)

```bash
npm run build
```

Статические файлы генерируются в директории `out/`.

## Сборка Android APK

Приложение можно собрать как нативный Android APK с помощью **Capacitor** — через Gradle из командной строки (без Android Studio) или через Android Studio.

### Требования

- **Android SDK** (установлен и настроен, переменная `ANDROID_HOME`)
- **Node.js** 18+
- **JDK 17+**

> Android Studio не обязателен. Достаточно установить Android SDK командной строки и JDK.

### Быстрая сборка через Gradle (без Android Studio)

**Отладочный APK** (для тестирования):
```bash
npm run apk:debug
```

**Релизный APK** (без подписи — для тестирования на устройстве):
```bash
npm run apk:release
```

Готовый APK будет в:
- Debug: `android/app/build/outputs/apk/debug/app-debug.apk`
- Release: `android/app/build/outputs/apk/release/app-release-unsigned.apk`

Эти команды выполняют всё за один шаг: сборку Next.js → синхронизацию с Android → сборку APK через `./gradlew`.

Для установки APK на устройство:
```bash
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

### Подпись релизного APK

Для публикации в Google Play или распространения подписанного APK:

```bash
# 1. Создайте keystore (один раз)
keytool -genkey -v -keystore nutriadvisor.keystore -alias nutriadvisor -keyalg RSA -keysize 2048 -validity 10000

# 2. Соберите подписанный APK
cd android
./gradlew assembleRelease \
  -PMYAPP_UPLOAD_STORE_PASSWORD=пароль_от_keystore \
  -PMYAPP_UPLOAD_KEY_PASSWORD=пароль_от_ключа \
  -PMYAPP_UPLOAD_KEY_ALIAS=nutriadvisor \
  -PMYAPP_UPLOAD_STORE_FILE=../nutriadvisor.keystore
```

Или настройте подпись в `android/app/build.gradle` → `signingConfigs`.

### Сборка через Android Studio

Если предпочитаете Android Studio:

```bash
npm run build:android
npm run open:android
```

Затем в Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

### Все доступные команды

| Команда | Описание |
|---|---|
| `npm run build:android` | Собрать Next.js + синхронизировать с Android |
| `npm run apk:debug` | Полный цикл: сборка + отладочный APK |
| `npm run apk:release` | Полный цикл: сборка + релизный APK (unsigned) |
| `npm run open:android` | Открыть проект в Android Studio |

### Настройка Android-проекта

Файл `capacitor.config.ts` содержит настройки:
- `appId: 'com.nutriadvisor.app'` — идентификатор приложения (меняйте при необходимости).
- `webDir: 'out'` — директория со статическим экспортом Next.js.
- Цвета сплеш-скрина и фона — `#059669` (emerald-600).

## Первый запуск

1. Откройте приложение в браузере или запустите APK на Android.
2. Перейдите на вкладку **Настройки** (шестерёнка в нижнем меню).
3. Нажмите **Добавить** провайдер — выберите тип (OpenAI, OpenRouter и т.д.) и укажите ваш API ключ.
4. Провайдер с ключом автоматически станет активным.
5. Заполните **Профиль** — укажите имя, параметры тела, выберите цели.
6. Всё готово — добавляйте приём пищи в журнале или общайтесь с AI в чате.

## Как это работает

### Хранение данных
Все данные хранятся в **IndexedDB** браузера через библиотеку Dexie.js. 5 таблиц:
- `providers` — конфигурации LLM-провайдеров и API ключи
- `userProfile` — профиль пользователя (параметры, цели, ограничения)
- `foodEntries` — записи о приёмах пищи
- `chatSessions` — сессии чата с AI
- `chatMessages` — сообщения чата

### LLM интеграция
Прямые HTTP-запросы к API провайдеров с ключами пользователя (формат OpenAI-compatible). Поддерживаются любые провайдеры с совместимым API:
- **OpenAI** (GPT-4o, GPT-4o-mini, ...)
- **OpenRouter** (DeepSeek, Claude, Llama, ...)
- **Alibaba DashScope** (Qwen, ...)
- **Ollama** (локальные модели, без интернета)
- **llama.cpp server** (локальные модели)
- Любые другие (вставьте свой Base URL)

Чат использует **SSE стриминг** (`stream: true`) — ответы появляются в реальном времени. Если провайдер не поддерживает стриминг — автоматически используется обычный запрос.

### Анализ еды
При анализе по фото происходит двухэтапный процесс:
1. **Vision-модель** описывает содержимое изображения.
2. Описание комбинируется с текстом пользователя (название блюда, вес) и передаётся в **промпт анализа питания**.

Результат парсится regex-ом для извлечения КБЖУ. Значения можно скорректировать вручную перед сохранением. Секция отладки позволяет увидеть промпты и ответ LLM.

### Контекстные промпты
Система автоматически определяет тему сообщения (ежедневный анализ, планирование, мотивация, обучение, проблемы со сном и т.д.) и подбирает соответствующий системный промпт, обогащённый данными профиля пользователя и сводкой питания за выбранный период.
