# Дизайн-концепции для продвижения — «Дневник Здоровья»

Статичные HTML-макеты **нового визуального дизайна** для оценки направления
перед редизайном приложения. Это маркетинговые/презентационные прототипы:
они показывают, как ключевые экраны могли бы выглядеть в карточке стора и
в постах. **Код приложения они не затрагивают и при сборке никуда не
попадают** (см. «Изоляция от сборки» ниже).

## Как открыть

- Быстро: открыть в браузере `design/concept-N/index.html` — это навигатор
  концепции с живыми миниатюрами всех экранов и ссылками на них.
- Или поднять локальный сервер: `npx serve design` (или
  `python3 -m http.server -d design 8000`) и открыть
  `http://localhost:8000/concept-1/` … `/concept-4/`.

Каждый файл полностью самодостаточен: HTML + один блок `<style>`, никаких
скриптов, внешних шрифтов, картинок и сетевых запросов. Размер макета —
390×844 (колонка телефона по центру страницы). Экраны связаны обычными
ссылками, нижняя навигация кликабельна.

## Общее для всех концепций

- **Одинаковый реалистичный контент** (день из жизни: 1 284 из 1 950 ккал,
  Б 96/140 · Ж 38/65 · У 112/180, силовая тренировка с таймером 12:47,
  диалог с ИИ, недельная статистика) — сравниваются именно визуальные
  системы, а не тексты.
- **6 экранов** в каждой концепции: `home` (дашборд), `diary` (дневник
  питания), `workout` (тренировка: конструктор + таймер), `stats`
  (статистика), `chat` (ИИ-чат), `profile` (профиль) + `index`
  (навигатор с миниатюрами).
- Нижняя навигация из 5 пунктов с акцентной центральной кнопкой «ИИ»;
  экран тренировки — модальный флоу без навигации.

## Концепция 1 — «Клиника»

**Стиль:** чистый светлый медицинский (референсы: Apple Health, Ada
Health). Посыл — «медицинская точность и доверие».

- **Палитра:** фон `#F4F7FB`, карточки `#FFFFFF`, текст `#10233F`,
  акцент — медицинский синий `#2E6BE6`; успех `#17A673`, предупреждение
  `#E8A13C`, ошибка `#E05252`; макросы: Б `#2E6BE6`, Ж `#E8A13C`,
  У `#14B8A6`.
- **Шрифты:** системный санс (`-apple-system, 'Segoe UI', Roboto`), цифры
  табличные; лестница 22/16/14/13/11.
- **Форма:** радиус 14px, тонкие бордеры `#E3EAF3`, мягкая двойная тень.
- **Сильные стороны для продвижения:** максимальное доверие аудитории
  30+, дружелюбно к старшему возрасту; выглядит «как приложение из
  рекламы Apple»; КБЖУ-цифры читаются мгновенно. Безопасный фаворит для
  карточки стора.

## Концепция 2 — «Полночь»

**Стиль:** тёмный premium/tech (референсы: Whoop, Oura). Посыл — «данные,
которые выглядят дорого».

- **Палитра:** фон `#0A0E14`, карточки `#111722` / `#18202E`, текст
  `#EAF1F9`; неоновый циан `#38D9F0`, лайм `#B7F04A`, янтарь `#FFC24B`;
  макросы: Б циан, Ж янтарь, У лайм.
- **Шрифты:** системный санс; uppercase-метки 11px с letter-spacing,
  крупные цифры 800.
- **Форма:** радиус 18px, тёмное стекло навигации с blur, дозированное
  неоновое свечение.
- **Сильные стороны для продвижения:** премиальный «спорткарный» образ,
  выделяется среди светлых конкурентов в сторе; сильная подача
  тренировок/статистики; хорошо работает в тёмных постах соцсетей.

## Концепция 3 — «Зен»

**Стиль:** тёплый friendly/zen (референсы: Headspace, Calm). Посыл —
«забота без тревоги».

- **Палитра:** кремовый фон `#F7F2EA`, карточки `#FFFFFF`, текст
  `#423A31`; шалфей `#6E9E7F`, абрикос `#EFA45B`, пыльно-голубой
  `#8AA6B8`, терракота `#D96C5F`; макросы: Б шалфей, Ж абрикос,
  У голубой.
- **Шрифты:** заголовки — Georgia (сериф), текст — системный санс.
- **Форма:** очень мягкие радиусы 22px, воздушные отступы (20–24px между
  секциями), деликатные тени.
- **Сильные стороны для продвижения:** эмоциональный контраст с
  «тревожными» счётчиками калорий — снижение барьера входа для
  аудитории похудения и wellness; сериф придаёт редакционную
  «дороговизну»; тёплая палитра отлично смотрится в постах.

## Концепция 4 — «Волна»

**Стиль:** энергичный sport с дозированным нео-брутализмом (референсы:
Strava, Nike Training Club). Посыл — «энергия, драйв, результат».

- **Палитра:** фон `#F6F6F4`, чернильный `#15181D` (тёмные
  карточки-акценты), раскалённый оранжево-красный `#FF4E2B`, вольт-лайм
  `#C6FF3D`, жёлтый `#FFB020`, зелёный `#2BB673`; макросы: Б красный,
  Ж жёлтый, У зелёный.
- **Шрифты:** системный санс, заголовки 800 с отрицательным
  letter-spacing, uppercase-лейблы 11px/700.
- **Форма:** фирменный приём — жёсткая тень `4px 4px 0` и бордер 2px
  только у 1–2 ключевых карточек и CTA на экран; тёмная навигация с
  лаймовым активным пунктом.
- **Сильные стороны для продвижения:** самый «кликабельный» CTA-стиль,
  сильная энергия для аудитории тренировок; мгновенно узнаваемые
  посты/баннеры; заметно отличается от типовых «зелёных» health-приложений.

## Изоляция от сборки

- Макеты лежат в `design/` в корне репозитория — вне `src/`, `public/`
  и `android/`.
- Сборка приложения (`npm run build`, статический экспорт Next.js в
  `out/`) не знает про этот каталог: в `out/` макетов нет, в APK они не
  попадают.
- Файлы не содержат скриптов и внешних запросов, поэтому безопасны и с
  точки зрения CSP/приватности — это просто статичные страницы.

## Статус

Черновики для выбора направления. Текущий стиль приложения не менялся и
продолжает использоваться, пока одна из концепций не будет утверждена;
перенос выбранной системы в `src/` — отдельная задача.
